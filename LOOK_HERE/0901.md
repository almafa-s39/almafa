# Module C — Solution Command Snippets

Minimal commands that satisfy each requirement only. No addressing or other
preparation commands included — these assume interfaces are already up and
addressed.

---

## Login blocking

Applied on every device, once.

```
login block-for 300 attempts 4 within 60
```

---

## IP source routing / neighbour discovery (CDP)

One line, global, on every device:

```
no ip source-route
```

CDP off only on the Yunhe-facing interface — IR1 G0/3, IR2 G0/3, IR3 G0/3,
BR1 G0/0, BR2 G0/0:

```
interface GigabitEthernet0/3
 no cdp enable
```

Everywhere else CDP stays on by default — no command needed there.

## Port security aging (inactivity-based, 10 minutes)

On every host-facing access port of AS1, AS2, AS3, AS4:

```
switchport port-security aging time 10
switchport port-security aging type inactivity
```

## PACL on AS2 (PC2 port)

```
ip access-list extended PACL-PC2
 deny tcp any 10.39.255.0 0.0.0.255 eq 22
 deny tcp any 10.39.255.0 0.0.0.255 eq 23
 deny tcp any host 10.39.110.11 eq 22
 deny tcp any host 10.39.110.11 eq 23
 deny tcp any host 10.39.110.12 eq 22
 deny tcp any host 10.39.110.12 eq 23
 deny tcp any host 10.39.31.11 eq 22
 deny tcp any host 10.39.31.11 eq 23
 deny tcp any host 10.39.41.11 eq 22
 deny tcp any host 10.39.41.11 eq 23
 permit ip any any
!
interface GigabitEthernet0/2
 ip access-group PACL-PC2 in
```

## VLAN access-map on VLAN 220 (DS3 and DS4, identical on both)

```
ip access-list extended VACL-PIPELINE-DENY
 permit tcp host 10.39.220.50 host 10.39.210.50 eq 22
ip access-list extended VACL-PIPELINE-PERMIT
 permit ip any any
!
vlan access-map PIPELINE-FILTER 10
 match ip address VACL-PIPELINE-DENY
 action drop
vlan access-map PIPELINE-FILTER 20
 match ip address VACL-PIPELINE-PERMIT
 action forward
!
vlan filter PIPELINE-FILTER vlan-list 220
```

## Unicast RPF

**IR1, IR2 (loose)** — on the Yunhe-facing interface, G0/3:

```
interface GigabitEthernet0/3
 ip verify unicast source reachable-via any
```

**IR3 (strict)** — G0/3:

```
interface GigabitEthernet0/3
 ip verify unicast source reachable-via rx
```

**BR1, BR2 (strict)** — G0/0:

```
interface GigabitEthernet0/0
 ip verify unicast source reachable-via rx
```
