# Samba 

guest access is disabled server-wide; SMB1 is disabled; SMB signing is required;

```conf
[global]
   map to guest = Never
   usershare allow guests = no
   restrict anonymous = 2

   server min protocol = SMB2_02

   client signing = required
   server signing = mandatory
```

the dropbox share has a recycle bin (vfs_recycle) that keeps deleted files for 7 days in .recycle inside the share;

```conf
[dropbox]
   vfs objects = recycle
   recycle:touch_mtime = yes
```

Deleting files older than 7 days with a cron job:

```
0 2 * * * /usr/bin/find /path/to/share/.recycle -type f -mtime +7 -delete
```

# FTP

all FTP activity is logged through syslog facility local2 so that task A9 can collect it centrally.

```conf
SyslogFacility LOCAL2 # default is daemon
SyslogLevel info # default is notice
```

# OpenVPN

OpenVPN status must be written to /var/log/openvpn/status.log (refreshed every 10 s) and connection events to syslog facility local3.

`server.conf`:
```conf
status status.log 10
syslog openvpn-server
verb 4
```

Syslog-ng config snippet:
```conf
source s_openvpn {
    system();
    internal();
};

filter f_openvpn {
    program("openvpn-server");
};

rewrite r_openvpn_facility {
    set-facility("local3");
};

destination d_openvpn {
    file("/var/log/openvpn/server.log");
};

log {
    source(s_openvpn);
    filter(f_openvpn);
    rewrite(r_openvpn_facility);
    destination(d_openvpn);
    flags(final);
};
```
